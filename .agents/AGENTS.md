# Rules
- After achieving a major feature, a major fix, or a big milestone, notify the user with a summary and ask them to push the code to their GitHub repository to ensure changes are continuously saved. Do NOT ask them to push on every minor change.
- When asking the user to push to GitHub, always provide the exact git add (specifying ONLY the exact file paths modified during the task, e.g. `git add path/to/file1 path/to/file2`, NEVER `git add .`), git commit (with a clear description), and git push commands so they can easily copy and paste them.
